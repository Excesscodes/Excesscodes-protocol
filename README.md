## Overview

EXCESS is a Solana token with a live market board built into its landing page. The board follows the busiest boosted Solana launches and keeps a reserved first row for the project's own line, which switches on the moment a contract address is published.

## Features

- Live board of the ten most traded boosted Solana tokens, refreshed every minute, paused while the tab is hidden
- Own-token row pinned first, with a branded placeholder until the contract address exists
- Moving tape fed by the same data
- One-click copy for the contract address and for every row
- Every outside fact lives in a single register; unconfirmed facts stay inert and carry no link
- Reduced-motion support throughout
