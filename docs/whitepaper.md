# EXCESS Whitepaper

## Vision

Value should be easy to see and easy to reach. EXCESS starts from a simple belief: a token earns attention by showing its work in public, from the first block, with nothing hidden behind a launch date.

## Mission

Build a Solana-native project that keeps its surroundings visible. The site carries a live board of the most active launches so every visitor sees the same flow the project sees, and the project's own line takes its place on that board the moment it exists.

## Roadmap

### Phase 1: Signal
The site and its live board go public. Every external fact is tracked in one register and shown as pending until confirmed.

### Phase 2: Launch
The contract goes live. The board's first row switches from its placeholder to live data and the address appears at the top of the site.

### Phase 3: Reach
Official channels open. Each one is listed on the site only after it is confirmed.

### Phase 4: Compound
Tools and partnerships that give holders more to do than watch.
